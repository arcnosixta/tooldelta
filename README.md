# ToolDelta

**See what an MCP update will break before your agent finds out.**

Offline, dependency-free comparison of saved MCP `tools/list` catalogs.
ToolDelta explains contract changes, flags declared capability drift, and
produces reports for humans and CI. Python 3.11+, Windows / macOS / Linux.

The first release is under construction. The project direction and competitor
research are recorded in [docs/MARKET.ru.md](docs/MARKET.ru.md).

MIT licensed. No network requests, server execution, API keys, or telemetry.
